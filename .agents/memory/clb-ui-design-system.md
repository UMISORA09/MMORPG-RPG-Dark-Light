# Chiến Long Bá — UI Design System Memory

Giao diện tựa game Chiến Long Bá sử dụng phong cách **Dark Fantasy Split-Screen Card & Cinema Slate Teal** đã được chuẩn hóa theo ảnh mockup thiết kế:
- **Canvas Nền Ngoài:** Muted Slate Teal `#4c6e6f` với radial gradient `#567c7d 0%` -> `#446364 75%` -> `#385253 100%`.
- **Khung Card & Modal:** Màu than trầm `#342a2b`, bo góc lớn `rounded-[34px]`, đổ bóng sâu `shadow-[0_30px_90px_rgba(0,0,0,0.55),0_10px_30px_rgba(0,0,0,0.4)]`.
- **Sub-panel & Input:** Màu nâu xám `#4a383a`, viền `#5d4648`, placeholder `#8e7a7c`, focus ring `#28c3e1`.
- **Nút Hành Động:** Nút viên thuốc `rounded-full`, màu cyan sáng `#28c3e1`, chữ đen đậm `#1c161a`, phát sáng `shadow-[0_0_25px_rgba(40,195,225,0.45)]`.
- **Artwork Pop-Out 2.5D:** Cột tranh chiếm 48-57% bên trái, tràn viền bo góc, mũi kiếm/vũ khí vươn ra ngoài mép trái không bị cắt tỉa.

Chi tiết và template code được lưu trữ trong skill: `.agents/skills/clb-dark-fantasy-ui/SKILL.md`.
Áp dụng quy chuẩn này cho tất cả màn hình: Shop, Inventory, Leaderboard, Skill Tree, Settings, Quest popups.
